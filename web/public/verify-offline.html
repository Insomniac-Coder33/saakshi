Check a file without trusting Saakshi

This page is a single file. It works in your browser and talks only to public Polygon servers, never to Saakshi. Save it, and it keeps working even if Saakshi is gone.

Checking

    A seal proves a file is unchanged since it was captured. It does not prove what the file shows.

    What this page checks
    1. The file’s own SHA-256, and that it splits back, byte for byte, into the 5-second pieces it was sealed as. A photo or journal entry is one piece.
    2. Each piece’s leaf, SHA-256(salt + fingerprint), climbs its Merkle proof to a root.
    3. Each root was written by the EvidenceAnchor contract at on Polygon Amoy (chain 80002), in a transaction that succeeded. Only Saakshi’s relayer can write to it. Its source code is verified.
    4. The receipt only tells this page where to look. Change any number in it and a check fails.

    Everything this page does is in its own source. Open it in a text editor to read it.
